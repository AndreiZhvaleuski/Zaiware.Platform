# OTP login — design prototype

A passwordless email + one-time-code sign-in screen, built on OpenDesign's
**glassmorphism** design system. Self-contained HTML: no build step, no dependencies,
no network calls. Open `index.html` in a browser.

**Demo code:** `123456` (anything else shows the error state).

## Design system

Taken from OpenDesign's shipped `glassmorphism` package, not invented:

| Token | Value | Use |
|---|---|---|
| Primary | `#1856FF` | primary action, focus ring, links |
| Text | `#141414` | body and headings |
| Surface | `#FFFFFF` | card and field surfaces |
| Secondary | `#3A344E` | deep neutral (available, unused) |
| Success / Danger | `#07CA6B` / `#EA2143` | confirmation / field error |

Layered on top: a translucent card (`rgba(255,255,255,.38–.55)` + `backdrop-filter`),
a pastel mesh backdrop, and a 22 px card radius with 14 px controls. All colors live as
CSS custom properties in one `:root` block — no raw hex in rules.

## Behaviour

1. **Email** — validates on first blur, then live-revalidates while invalid; error copy
   states the cause and the fix.
2. **Code** — six boxes, paste-aware, auto-advance, auto-submit on the sixth digit,
   30 s resend countdown, "change email" escape hatch.
3. **Done** — confirmation echoing the address.

Accessibility and state handling follow OpenDesign's craft rules
(`state-coverage`, `form-validation`, `accessibility-baseline`, `animation-discipline`):
`aria-invalid` + `aria-describedby`, polite `role="status"` announcements, `aria-busy`
with locked inputs while pending, focus moved to the new heading on step change, 44 px+
targets, 150 ms state transitions, `prefers-reduced-motion` respected, and a `@supports`
fallback when `backdrop-filter` is unavailable.

`od lint` reports **0 P0 / 0 P1 / 0 P2**.

## Not production code

The flow is simulated: `setTimeout` stands in for the send-code and verify calls, and
`DEMO_CODE` is a constant. To wire it up, replace the two timeouts in the inline script
with real requests and remove the "Prototype demo" hint. The email is never sent anywhere.

## Provenance

Created in OpenDesign (project id `otp-login`), promoted from a comparison of five
shipped systems (linear-app, stripe, vercel, glassmorphism, notion) and exported here as
a single flat file so the design lives in git beside the code it describes.

The comparison variants were intentionally not kept: they were generated by layering a
per-system override block over this file, so they would rot the moment `index.html`
changed. Recreate them from OpenDesign if the comparison is ever needed again.
