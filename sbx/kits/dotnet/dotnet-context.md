# .NET SDK

- `dotnet` and `dotnetup` are preinstalled and on `PATH`.
- `dnx` (.NET 10's `dotnet tool exec` runner) is preinstalled and on `PATH` alongside `dotnet`.
- `DOTNET_ROOT` is already configured for AppHost executables launched directly, such as Aspire/DCP.
- Use the baked SDK for normal tasks; do not reinstall .NET.
